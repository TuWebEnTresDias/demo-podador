# Copa Sur · Demo de poda y arbolado

Landing estática de demostración para TuWebEn3Días. La marca Copa Sur y la imagen generada son ilustrativas. La página no indexa y usa rutas relativas para funcionar en el subdirectorio de GitHub Pages.

## Personalización

- `e` establece la marca. Si no se informa, se puede usar `n` o mantener **Copa Sur**.
- `t` admite un número argentino en formato nacional de 10 dígitos o con prefijo +54 o +549. Se permiten espacios, guiones, paréntesis y puntos. Un valor inválido o repetido deshabilita el contacto.
- Sin `t`, WhatsApp abre el mensaje con el selector de destinatario, igual que en la demo de vidriería.
- Los datos de la consulta se conservan en el navegador durante la visita. El enlace preparado abre WhatsApp para que la persona revise y envíe el mensaje.

## Referencias de diseño

El catálogo de [UI/UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) orientó la estructura **Hero + Features + CTA** y la adaptación visual del criterio de **Hyperlocal Services**. Las demos de [electricista](https://github.com/TuWebEnTresDias/demo-electricista) y [vidriero](https://github.com/TuWebEnTresDias/demo-vidriero) sirvieron de referencia para el recorrido de consulta y el contacto por WhatsApp.

## Publicación

El sitio se puede servir desde la raíz de `main` en GitHub Pages. No requiere instalación ni paso de compilación.
